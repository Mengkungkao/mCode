Connect this browser

On the device, open mCode › Settings › Desktop IDE › Pair a computer and scan its QR code with this phone's camera, or type the 6-digit code it shows:

A browser with full access can also show a pairing code: Settings › Security › Pair a phone or computer.

Only browsers you pair can open projects here. Flashing a board always asks first. On a network you do not trust, use an HTTPS tunnel (see mCode's Security guide).
